# Grill-Me 珠宝展示质量研究

## 反推结论

高质量并不等于统一的“珠宝摄影感”。稳定结果来自六个可独立控制的层次：

1. **展示任务明确**：完整目录图、三分之四结构图、英雄特写、工艺细节和佩戴场景必须分开生成。
2. **商品组成准确**：成对耳饰要锁定两件、同款、同尺度；单体商品要完整显示扣具、戒臂或环形结构。
3. **设计身份前置**：主石数量和切形、轮廓、连接结构必须早于风格词，减少长提示词导致的改款。
4. **材质按物理特性描述**：金属依赖连续反射带，刻面宝石依赖切面和内部反射，翡翠、欧泊、珍珠、珐琅各有不同光学语言。
5. **背景服务于轮廓分离**：默认白到浅灰；浅色金属和材料用窄暗边、轻微灰阶或接触阴影分离，不用彩色氛围光。
6. **生成后选择与修复**：提示词不能保证每张图都完整。必须先做结构硬门槛，再评分，并只针对失败维度重试。

## 展示档案

| 档案 | 核心控制 | 常见失败 |
|---|---|---|
| `catalog-front-full` | 近正交正面、完整商品、65%-75%占比、安全边距 | 微距词导致裁切，成对商品少一件 |
| `catalog-three-quarter` | 正面与三分之四配合，展示厚度、耳针、背托和连接 | 两只耳饰变成不同设计，尺度不一致 |
| `sculptural-product` | 单体三分之四、结构轮廓完整、自然接触阴影 | 戒环或手镯断裂，吊坠漂浮 |
| `hero-macro` | 明确视觉焦点和允许裁切范围，另有完整产品图 | 被误作默认交付，无法核验完整结构 |
| `craft-detail` | 纹理、纤维、结体和连接路径清楚 | 细节图冒充完整产品图 |
| `wearing-or-scene` | 基于通过 QA 的产品图锁定身份再换场景 | 直接从文字生成导致产品身份漂移 |

## 材质规则摘要

| 材质族 | 正向信号 | 失败信号 |
|---|---|---|
| 抛光贵金属 | 连续明暗反射带、真实色相、边缘与厚度 | 塑料、橙色涂层、死黑或过曝 |
| 白金 / 铂金 | 中性银白、窄暗边分离白底 | 灰塑料、无轮廓、廉价镀铬 |
| 哑光 / 锤纹金 | 细密纹理、宽柔高光 | 粗糙噪点、强制镜面 |
| 刻面宝石 / 钻石 | 清晰刻面、体色、内部反射、受控亮点 | 彩色玻璃、乳白块、星芒泛滥 |
| 欧泊 | 半透明体内变彩、色斑深浅变化 | 表面印花、均匀霓虹 |
| 翡翠 | 蜡状光泽、棉絮云雾、色根、边缘透光 | 玻璃、亚克力、荧光绿 |
| 珍珠 | 宽柔高光、珍珠层、轻微虹彩 | 陶瓷球、塑料珠 |
| 珐琅 | 有厚度的饱和色层、圆润高光、干净边界 | 树脂感、溢色 |
| 绳结 / 织物 | 可读纤维、正确编织路径和张力 | 熔化、断裂、软泥感 |

## Seedream 5.0 Pro 实测

### 配置

- 即梦会话：`Grill-Me珠宝5Pro提示词测试`
- Session ID：`19824577550860`
- 模型：Seedream 5.0 Pro
- 输出：4K，4096 x 4096，1:1
- 样本：3 个设计族 x 4 个提示词版本 x 每版 2 张，共 24 张
- 消耗：12 个任务，共 288 积分
- 设计族：抛光黄金与心形海蓝宝、欧泊与纹理黄金、冰绿翡翠山形耳钉

### 变量

- A：只描述设计与“白底产品摄影”的短基线。
- B：增加通用影棚、完整性、视角和结构说明。
- C：加入长版展示控制、结构、材质光学和负面词。
- D：保留精确数量、完整性、主体占比、安全边距和单一材质模块的精简版。

### 结果

- 5.0 Pro 的金属、刻面宝石、欧泊和翡翠基础表现已经很强，A 也能偶然得到优秀材质。
- B 通常提高视角和结构可读性，但不能保证完整构图。
- C 的材质描述有效，但长提示词会稀释商品数量、完整性和设计身份；“微距”相关词尤其容易触发裁切。
- D 在欧泊和翡翠各得到一张完整且高质量的结果，同时另一张仍发生裁切；黄金与海蓝宝两张都出现不同程度的设计身份漂移。
- 因此不存在单个“万能高质量后缀”。最佳策略是短提示词、按展示档案和材质选择模块、每次生成多个结果、硬门槛筛选、对失败项定向重试。

## 推荐提示词骨架

```text
高质量珠宝产品图，[展示档案]。[商品品类、准确数量、成对关系和视角]，[锁定主石、轮廓、结构与候选变化]。[镶嵌、连接、厚度和佩戴结构]。[仅选中的材质光学模块]。无缝纯白或极浅中性灰背景，主体约占画面65%-75%，四周保留安全边距，柔和影棚光，轮廓与背景分离，自然接触阴影，焦点准确、边缘清晰、商业级克制精修。无文字、Logo、水印、品牌复刻、无关道具、多余珠宝、错误数量、漂浮结构和未声明材质。
```

不要把这段机械追加到所有任务。先删去不适用的内容，再确保设计身份、展示完整性和材质模块各只出现一次。
