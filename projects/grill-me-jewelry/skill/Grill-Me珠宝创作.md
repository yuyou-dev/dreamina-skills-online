# Grill-Me珠宝创作

分为**交互阶段**和**执行阶段**。交互阶段完成四轮探索、候选矩阵和独立确认；执行阶段只使用已确认简报生成设计图、检查数量与质量并交付。

参数优先级：用户本轮明确要求 > 当前面板或会话默认设置 > 本技能声明的默认值 > 工具能力约束 > 通用缺省值。不得用本技能默认值覆盖用户已有设置。

`generate_form_for_info_collection` 只收集文字、单选和多选信息；图片、草图、裸石图、已有珠宝图或其他附件必须由用户在对话中上传或使用当前会话已有资源，不得通过表单收集。

## 一、触发与路由

| 条件 | 路由 |
|---|---|
| 用户明确说“Grill Me 珠宝”“深度问我”“帮我探索到底要设计什么” | 强制完成四轮探索，即使部分信息已知 |
| 工作流、珠宝身份、输出形态三者都无法从文字和素材推断 | 进入四轮探索 |
| 工作流已知，只缺品类、材质或一两个关键字段 | 不进入 Grill Me；用一次合并表单补齐后执行明确任务 |
| 品类、设计目标和输出已经清楚 | 不进入 Grill Me；按明确需求直接执行 |

显式 Grill Me 请求本身就是充分触发条件。不得因为用户已给出一两项信息而缩短为普通问卷。

## 二、工具映射

| 工具 | 使用时机 | 下一步 |
|---|---|---|
| `generate_form_for_info_collection` | 四轮探索、简报确认或修正受影响字段 | 更新累计状态，不重复已解决问题 |
| `creation_agent_search` | 已确认简报需要文化、工艺或风格事实依据 | 把结果转成原创设计约束，不复制品牌款 |
| `text2image` | 从零开始或只有文字构思 | 每个候选单独生成并进入 QA |
| `image2image` | 有草图、已有珠宝、裸石、材料或元素参考 | 明确输入角色、保留项和可变项后生成候选 |
| `image_super_resolution` | 用户要求高清且结构、展示与材质检查全部通过 | 输出高清候选，不用超分掩盖结构或质感错误 |

图片默认使用 Seedream 5.0 Pro 的 4K 版。模型与清晰度分别继承；某一项在用户和当前面板都未设置时，才对该项使用本技能默认。默认输出白底或极浅灰白背景、完整展示商品组成的高质量珠宝产品图；用户明确要求佩戴、场景、包装、广告或局部特写时才改变展示方式。

## 三、交互阶段

### 3.1 状态规则

- 四个探索阶段必须各完成一轮提交，之后才能进入独立确认轮。
- 每轮只问 1-4 个当前可回答字段，不得超过 4 个。
- 已知事实不重复询问；该阶段基础事实已知时，改问本阶段更深的未决问题，不跳过阶段。
- 每轮提交后，用一段短摘要重述新增事实和累计结论，再进入下一阶段。
- 早先答案保持有效，只有用户明确修正时才更新。
- 不替用户回答审美、意义、情感或取舍问题。
- 选择题提供“其他”与自定义文本路径。

### 3.2 第一轮：创作地基

调用 `generate_form_for_info_collection`，从下列字段选择最多 4 个未解决字段：

| 字段 ID | 目标 | 缺失时选项 |
|---|---|---|
| `workflow_family` | 原创设计、参考演化、草图成品化、裸石配款、展示图或其他 | 提供单选与其他 |
| `jewelry_type` | 戒指、项链、耳环、手链、吊坠、胸针、套装或其他 | 提供单选与其他 |
| `starting_point` | 从零、文字雏形、草图、已有珠宝、裸石/材料、元素/风格参考 | 提供单选与其他 |
| `delivery_count` | 交付数量 | `count_1`、`count_2`、`count_4`、`count_8`、自定义数量 |

用户已经用明确数量表达指定交付数时原样锁定，不得重问或缩减，例如“1款”“2款”“四款”“8张”。“一枚戒指”“做一个版本”“给我一个方向”等单数对象或版本表达不视为明确指定交付 1 款，仍须在本轮确认 `delivery_count`。

### 3.3 第二轮：意义内核

调用 `generate_form_for_info_collection`，根据未决状态从以下维度选择最多 4 个：

- `wearer_recipient`：佩戴者或赠予对象。
- `occasion`：日常、纪念、婚礼、典礼、收藏或其他场景。
- `emotional_intent`：克制、守护、力量、自由、浪漫、神秘等情绪目标。
- `story_symbolism`：故事、主题、意象或象征。
- `cultural_boundary`：必须尊重或避免的文化边界；仅在会改变设计时询问。

如果对象和场景已知，使用情绪、象征和文化边界等更深问题完成本阶段。

### 3.4 第三轮：设计语言

调用 `generate_form_for_info_collection`，从下列未决字段选择最多 4 个：

- `design_system`：高级珠宝、当代极简、古董、建筑、雕塑、有机、东方工艺等。
- `silhouette_motion`：几何、流线、包裹、放射、悬浮、非对称运动等。
- `visual_weight`：轻盈、平衡、饱满、戏剧化。
- `hero_material_gem`：主材质、主石、配石语言和金属颜色。
- `finish_craft`：镜面、哑光、錾刻、花丝、密钉、包镶、微珠边等。
- `reference_role`：用户素材分别用于结构、石材、风格、工艺、颜色或构图。

不得编造宝石等级、产地、证书、价格、品牌信息或附件中不存在的细节。

### 3.5 第四轮：变化与交付

调用 `generate_form_for_info_collection`，优先解决：

| 字段 ID | 内容 |
|---|---|
| `output_family` | 完整正面白底、三分之四结构展示、雕塑型产品展示、明确裁切的英雄特写、工艺细节、佩戴展示、系列探索或只要文字简报 |
| `render_profile` | 展示档案、背景、构图、视角、边缘分离、光线和阴影；未指定时按品类自动选择 |
| `locked_facts` | 品类、佩戴逻辑、核心故事、指定材质、必须保留结构 |
| `flexible_axes` | 轮廓、镶嵌、元素转译、宝石布局、负空间、表面工艺 |
| `exploration_spread` | 稳健、平衡、宽幅或实验性探索 |
| `required_asset_status` | 必须素材是否已上传；仅在执行依赖素材时使用 |

本轮最多 4 个字段。需要某张源图但尚未上传时，在表单外明确要求上传，并在素材到位前停止确认与出图。

## 四、候选矩阵

当 `delivery_count >= 2` 时，在确认前建立候选矩阵：

- 固定：珠宝品类、佩戴逻辑、核心故事、用户锁定材质和必须保留结构。
- 可变：轮廓、镶嵌结构、元素转译、宝石布局、负空间、表面工艺。
- 每个候选至少改变 3 个可见设计轴；只改形容词、颜色、背景、镜头或光线不算有效差异。
- 同批候选共享展示档案、背景、视角、光线和质量标准，使差异来自设计本身。
- 不得擅自加入可转换、双用或机械结构。
- 锁定项导致不足 3 个可变轴时，必须要求用户放宽限制或把数量改为 1，不得伪造差异。

默认分支顺序：

| ID 顺序 | 分支角色 | 差异方向 |
|---|---|---|
| 1 | 商业核心 | 清晰焦点、可佩戴比例、克制元素转译 |
| 2 | 雕塑重构 | 重建轮廓、加强体量、改变负空间 |
| 3 | 工艺签名 | 改变镶嵌系统、表面处理和材质连接 |
| 4 | 叙事重译 | 用不同可见结构表达同一故事 |
| 5 | 轻量化 | 降低体量、增加通透、简化配石节奏 |
| 6 | 建筑几何 | 模块秩序、结构重复、清晰空间逻辑 |
| 7 | 高珠戏剧 | 放大尺度节奏、丰富宝石编排和仪式感 |
| 8 | 系列节奏 | 重复签名单元，形成可延展系列语言 |

使用前 N 个角色作为起点，再按用户确认的可变轴改写。每个候选使用稳定 ID `GM-01` 至 `GM-N`。

## 五、独立确认门

四轮完成且必须素材已到位后，输出共享简报、锁定项、可变轴、数量和候选矩阵，再调用 `generate_form_for_info_collection`：

| 字段 ID | 选项 |
|---|---|
| `brief_action` | 确认并执行 / 修改简报 / 只保留文字简报 |
| `brief_corrections` | 可选修正文本 |

- 确认前禁止调用 `text2image`、`image2image` 或创建任何生成任务。
- 选择“修改简报”时只回到受影响字段，保留其他答案，更新候选矩阵后再次确认，不重跑四轮。
- 选择“只保留文字简报”时直接交付确认版简报，不调用图片工具。

## 六、执行阶段

### 6.1 工具路由

| 已确认输入 | 执行 |
|---|---|
| 从零开始或只有文字构思 | 每个候选独立调用 `text2image` |
| 草图、已有珠宝、裸石、材料、元素图或产品图 | 每个候选独立调用 `image2image` |
| 需要文化、工艺或风格事实依据 | 先调用 `creation_agent_search`，转成原创约束后生成 |
| 展示图且已有确认产品图 | `image2image` 锁定产品身份，只改变佩戴者、场景或构图 |
| 展示图但尚无产品图 | 先生成并检查珠宝设计图，再基于通过结果生成展示图 |
| 用户要求高清 | 结构、身份、完整性、材质和展示评分全部通过后调用 `image_super_resolution` |

候选之间没有依赖时并行生成；“先产品、后展示”和“先结构检查、后超分”必须串行。

### 6.2 展示档案

先确定一个展示档案，再编译提示词。不得把所有档案的镜头词混在一起。

| 档案 | 适用 | 构图与视角 |
|---|---|---|
| `catalog-front-full` | 默认；耳环、吊坠、胸针及需要读清正面设计的产品 | 近正交正面，商品组成完整可见，主体约占画面 65%-75%，四周保留安全边距 |
| `catalog-three-quarter` | 需要展示厚度、耳针、戒臂、扣具、背托或连接关系 | 三分之四视角；成对耳饰可一只正面、一只三分之四，比例一致、同属一款 |
| `sculptural-product` | 戒指、手镯、雕塑型吊坠和立体结构 | 单款三分之四产品视角，结构轮廓完整，接触阴影说明落地关系 |
| `hero-macro` | 用户明确要求广告级近摄或宝石英雄特写 | 允许有意裁切，但必须先声明裁切边界和视觉焦点；不得作为默认产品图 |
| `craft-detail` | 錾刻、花丝、绳结、织物、锤纹等工艺 | 俯拍或近摄，纹理与连接路径清楚；明确这是细节图，不替代完整产品图 |
| `wearing-or-scene` | 用户明确要求佩戴或场景展示 | 必须先有通过 QA 的产品图，使用 `image2image` 锁定产品身份后改变人物、场景或构图 |

成对耳饰、袖扣等商品用“单款独立图片，按商品组成完整呈现，两件数量准确、比例一致”，不得写成“单件珠宝”。手镯、戒指、项链等单体商品写“单件完整呈现”。

默认背景为无缝纯白到极浅中性灰。白金、铂金、珍珠或冰种浅色材质容易融入白底时，使用极浅中性灰、窄而柔和的深色边缘反射或略深的接触阴影做轮廓分离，不得把金属压成灰色，也不得使用彩色氛围光污染材质。

### 6.3 材质光学模块

只选择设计中真实存在的模块，每类材质写 1-2 句。不要把钻石火彩套用到翡翠、欧泊、珍珠或珐琅。

| 材质 | 有效描述 | 明确避免 |
|---|---|---|
| 抛光黄金 / 玫瑰金 | 真实贵金属暖色反射，连续平滑的明暗反射带，暗部仍保留反射信息，边缘与厚度清楚 | 橙色涂层、塑料、过曝成纯黄 |
| 白金 / 铂金 | 中性银白，亮而不过曝，窄暗反射边勾勒白底轮廓，抛光面连续 | 灰塑料、廉价镀铬、无边界 |
| 哑光 / 古法 / 锤纹金 | 细密均匀的砂面或锤纹，宽而柔的高光，凹凸与边缘保留 | 强制镜面、粗糙噪点、泥感 |
| 刻面彩色宝石 | 刻面交界清晰，冠部与亭部关系合理，真实体色和内部反射，少量受控亮点 | 彩色玻璃、无切面、遍布星芒 |
| 钻石 | 透明层次、清晰刻面与受控白色火彩，爪镶边界可读 | 乳白石块、爆炸星芒、过曝 |
| 欧泊 | 半透明体内有蓝绿为主的变彩，色斑深浅不一且自然过渡 | 表面印花、霓虹贴图、均匀荧光 |
| 翡翠 / 玉石 | 冰润半透明或温润蜡状光泽，天然棉絮、云雾与色根，边缘有柔和透光 | 玻璃、亚克力、荧光绿、无内部层次 |
| 珍珠 | 珍珠层光泽，宽柔高光、轻微虹彩与细腻明暗过渡 | 陶瓷球、塑料珠、硬白斑 |
| 珐琅 / 漆艺 | 饱和但有厚度的色层，圆润连续高光，与金属边界干净 | 廉价树脂、溢色、塑料玩具感 |
| 绳结 / 织物 | 纤维可读，编织路径、张力和结体正确，与金属连接可信 | 熔化纤维、断裂路径、软泥感 |

### 6.4 提示词编译顺序

每个 `GM-xx` 使用相同顺序写成一段可直接执行、不过度堆词的提示词：

```text
1. 展示类型：高质量珠宝产品图，以及选定的 render_profile。
2. 精确商品：品类、数量、成对关系、正面/三分之四视角和完整性。
3. 设计身份：必须保留的主石、轮廓、佩戴逻辑、结构和当前候选三个可见变化轴。
4. 制作结构：镶嵌、支撑、连接、厚度、链路、戒臂、扣具或耳针。
5. 材质光学：只插入实际存在的金属、宝石和工艺模块。
6. 画面控制：背景、主体占比、安全边距、轮廓分离、柔和影棚光和接触阴影。
7. 清洁度：焦点准确、边缘清晰、商业级克制精修、无脏污划痕。
8. 禁止：文字、Logo、水印、证书、价格、品牌复刻、无关道具、多余珠宝、错误数量、漂浮结构、未声明材质。
```

不要加入“杰作、8K、电影感、体积光、光线追踪、Octane、极浅景深、f/1.4、梦幻散景”等与白底珠宝结构和材质无直接关系的词。不要同时要求“完整产品”和“微距裁切”；需要两种交付时分别生成完整产品图与特写图。

有参考图时，明确每张图只承担产品身份、结构、材质、工艺、颜色、风格或构图中的哪些角色，并写出允许变化；不得复制参考图中的品牌款、文字、Logo 或水印。

### 6.5 Manifest 与数量守恒

```Markdown
| candidate_id | branch_role | tool | input_role | locked_facts | changed_axes | status | retry_count |
|---|---|---|---|---|---|---|---|
```

- 一款对应一张独立图片；合集图不能抵扣数量。
- `requested_count` 等于确认的 `delivery_count`。
- 每个 ID 最终只能是 `done` 或 `failed`，失败项不得从清单消失。
- `missing_count = requested_count - done_count`；大于 0 时不得声称完整交付。

## 七、质量检查与重试

### 7.1 硬门槛

任一项失败即判定该图不可交付，不进入超分：

- 品类、商品数量、成对关系和佩戴逻辑正确。
- 主石、指定材质、核心轮廓和锁定结构保持一致，没有多石、少石或擅自改款。
- 默认产品图完整可见且保留安全边距；只有已确认的 `hero-macro` 或 `craft-detail` 允许有意裁切。
- 镶嵌、支撑、连接、厚度、耳针、扣具和比例具有可制作逻辑，没有漂浮、穿插、熔化或断裂。
- 单款独立图片，无拼图、无关珠宝、文字、Logo、水印、证书、价格和虚构参数。
- 多候选分支至少有 3 个可见设计差异轴，且数量与 Manifest 一致。

### 7.2 质量评分

硬门槛通过后，每项 0-2 分，总分至少 9 分且任何单项不得为 0：

| 维度 | 2 分标准 |
|---|---|
| 构图与背景 | 主体比例合适、边距安全、背景干净、商品完整且视觉重心稳定 |
| 对焦与边缘 | 主体对焦准确，宝石、爪镶、轮廓和连接边缘清楚，无错误景深 |
| 金属表现 | 色相真实，反射带连续，亮部不过曝、暗部不死黑，无塑料感 |
| 宝石与材料 | 对应材质的透明度、光泽、内部层次、切面或纹理成立，无玻璃和树脂感 |
| 光线与阴影 | 柔和影棚光能解释体积，轮廓与背景分离，接触阴影自然且没有彩色污染 |

### 7.3 定向重试

失败时保留原 `GM-xx`，记录具体失败项，只增加一组修复约束并重试，最多 2 次：

| 失败 | 修复约束 |
|---|---|
| 产品被裁切或过大 | 改为完整商品目录图，主体约占 65%-70%，四周至少 10% 安全边距，删除微距、特写和浅景深词 |
| 成对数量或比例错误 | 明确“同一款成对两件、数量准确、尺寸一致、均完整可见”，删除可能引入额外物件的描述 |
| 设计身份漂移 | 缩短装饰描述，把必须保留的主石数量、切形、轮廓、结构放到提示词前部，使用 `image2image` 锁定通过的产品图 |
| 金属像塑料 | 只重申对应金属模块的反射带、色相、边缘与厚度，删除“发光、霓虹、超亮”等词 |
| 宝石或材料失真 | 只重申对应材质的光学模块和天然内部特征，删除不属于该材质的火彩或透明词 |
| 白色材质融入背景 | 使用极浅中性灰背景、窄暗反射边和稍深接触阴影，保持材质本色 |
| 结构不合理 | 明确支撑、连接、镶嵌和厚度，减少装饰元素；不得用超分修复 |

多图生成时先从通过硬门槛且评分最高的结果中选择，不因同一提示词偶然产出一张好图就跳过 QA。连续失败后标记 `failed` 并计入 `missing_count`。
