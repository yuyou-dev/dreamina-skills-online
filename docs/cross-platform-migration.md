# Cross-Platform Skill Migration

跨项目迁移按六个步骤执行：

1. 来源审计：只读确认源 Skill、插件、MCP、UI、脚本、测试和真实依赖。
2. 行为提取：记录触发边界、输入、状态变化、确认门、输出、质量门和失败条件。
3. 工具映射：把源平台工具映射到即梦官方工具；无法映射的能力必须删除、内联或改写。
4. 依赖消除：移除子 Skill 路由、插件 UI、MCP 发现、CLI、provider job 和本地文件依赖。
5. 单文件改写：把运行必需规则写入一个自包含 `skill/*.md`，维护证据留在 `references/`。
6. 场景验收：覆盖触发、非触发、缺失输入、确认门、工具路线、默认覆盖和失败处理。

导入 Project 的 `origins` 必须记录公开仓库 URL、提交、源路径和哈希；`references/source-audit.md` 说明保留、删除和改写的能力。

当前不建立通用中间语言或自动转译器。出现至少两个结构相近、需要重复机械转换的源平台后，再基于实际重复提炼 adapter。
